# Glossary

| Term | Meaning in TopLabel |
|---|---|
| Item | One thing in a layout row: a set symbol, a text, a set code or mana symbols |
| Layout | The rows of a label or divider with their items, margin, gap and symbol size |
| Base | The flat plate every label is built on |
| Border | The shape mtg-vectors draws behind a symbol (black, or white for commons) |
| Depth profile | The base thickness and how far the symbol and text stand above or sink into the base |
| Back face | The face of a divider that lies on the print bed; it can carry the content mirrored, flush or engraved |
| Detailed | Symbol style that prints the symbol without its border |
| Divider | A plate that stands in a card drawer, with the symbol and text in its top band and a pattern of holes below |
| Element | The symbol or the text block of a label |
| Engrave | Cut an element into the base and leave the pocket empty |
| Filament slot | The number of the filament a part prints with in the slicer |
| Flush inlay | An element sunk into the base and level with its top, printed in its own color |
| Library | The set symbols, watermarks, set list and icons kept on the server |
| mtg-vectors | The open repository of Magic set symbols on GitHub that TopLabel downloads |
| Mana symbol | A Magic mana symbol from Scryfall, printed as a pip or an icon |
| Palette | The list of filament slots with their names and colors |
| Pip | The round mana symbol with its icon cut out of it |
| Pattern | The holes cut through a divider below its top band, or Solid |
| Part | One solid in the export: the base, the symbol (or its outline and fill) or the text |
| Row | One band of a layout, top to bottom, holding items side by side |
| Rarity | The version of a set symbol: common, uncommon, rare, mythic, special, timeshifted, watermark or a variant |
| Scryfall | The Magic card database TopLabel takes the set list and fallback icons from |
| Scryfall icon | The single-color set icon Scryfall shows, used when mtg-vectors has no symbol |
| Set code | The short code of a set, for example NEO |
| Silhouette | Symbol style that prints the whole outline, border included |
| Sunk | How deep an element goes into the base |
| Tab | The narrower lower part of a divider that slots into the drawer |
| Text area | The part of the label kept for the text, as a percentage |
| Top band | The solid strip along the top of a divider that holds the symbol and text |
| Two-tone | Symbol style that prints the border and the symbol as two parts in two colors |
| Watermark | A faction, guild or land symbol from mtg-vectors, used as a label symbol without a set |
