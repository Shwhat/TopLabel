# Screen layout

TopLabel has a menu bar and ribbon at the top, the Sets panel on the left, the work area in the middle with the Saved labels panel under it, the Properties panel on the right and the status bar at the bottom.

## Menu bar

| Menu | Items |
|---|---|
| File | New label, Open saved label, Save, Save as, Rename label, Delete saved label, Export, Export Bambu Studio 3MF, Export STL, Change password, Sign out |
| Edit | Undo, Redo, Add text line, Show or hide the symbol, Show or hide the text, Reset label to defaults |
| Label | Size, Arrangement, Save arrangement, Make arrangement the default, Manage arrangements, Depth, Save depth profile, Save size preset, Manage presets, Filament colors, Two-tone symbol on or off |
| Library | Refresh library, Library information, Fonts, Show sets, Show lands and watermarks |
| Export | Export (the dialog), and one item per format |
| View | 2D layout, 3D preview, Both views, Fit the label in the view, Layout guides on or off, Dark theme on or off, Dark work surface on or off, and show or hide each panel |
| Help | Keyboard shortcuts, Open demo labels, About TopLabel |

The name of the open label is shown to the right of the menus, with "(not saved)" for a label that has never been saved and "(changed)" for a saved label with changes. On the server, your user name at the far right opens the account menu: About TopLabel, Change password and Sign out.

## Ribbon

| Tab | Groups and buttons |
|---|---|
| Home | Label: New label, Save, Save as, Open. Edit: Undo, Redo. Export: Bambu 3MF, STL, Export. View: 2D layout, 3D preview, Both |
| Label | Size: Size. Arrangement: Arrangement, Save arrangement, Make default. Depth: Depth, Save depth. Colors: Filament colors, Two-tone symbol |
| Insert | Elements: Symbol, Text, Add text line. Symbols: Sets, Lands and watermarks |
| Library | Refresh library, Library info, Fonts |
| View | Views: 2D layout, 3D preview, Both, Fit. Show: Layout guides, Panels. Theme: Dark theme, Dark work surface |
| Help | About, Shortcuts, Demo labels |

Buttons that switch something on or off are highlighted while it is on. The chosen tab is remembered.

## Sets panel

The Sets panel has two views, chosen at its top: **Sets** and **Lands and watermarks**. See [Sets and the symbol library](/about/sets-and-library).

## Work area

The header shows the label name, its set code and date, the arrangement, the text size used and the symbol size. On the right, the view switch chooses **2D layout**, **3D preview** or **Both**, and **Fit** brings the whole label back into view.

| View | Shows |
|---|---|
| 2D layout | The label from above in its filament colors, with its width and height. Layout guides show the margin (white), the symbol area (blue) and the text area (orange). Engraved parts are shown darker. |
| 3D preview | The label as it will print. Drag to turn it, right drag or Shift drag to move it, and use the wheel to zoom. The boxes at the bottom left show or hide each part. |

## Properties panel

The Properties panel shows the open label: its name and set at the top, warnings in amber boxes, then the groups Label, Arrangement, Symbol, Text, Depth and Colors. Every change applies at once and can be undone. The fields are described in [Labels and elements](/about/labels-and-elements).

## Saved labels panel

Lists the labels saved under your account with their set, size, arrangement and when they were saved. Click a row to open that label; Delete removes it after asking.

## Panels

Drag the inner edge of a panel to resize it. View, Hide or Show each panel, or the Panels button, hides and shows them. Sizes and visibility are remembered.

## Status bar

| Item | Shows |
|---|---|
| Size | Width and height of the label and its total height |
| Parts | Number of parts and triangles, or "Building..." while the label is being rebuilt |
| Warnings | Number of warnings; click to show them in the Properties panel |
| Library | When the library was downloaded and how many sets it has |
| Message | Short confirmation of the last action, at the right |

## About screen

Help, About TopLabel opens this guide in the work area. Close it with Escape or Close.
