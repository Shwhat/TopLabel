# Keyboard shortcuts

Help, Keyboard shortcuts (F1) shows this list in TopLabel.

## Labels and files

| Keys | Action |
|---|---|
| Ctrl+N | New label |
| Ctrl+Shift+N | New divider |
| Ctrl+O | Open a saved label |
| Ctrl+S | Save the label |
| Ctrl+Shift+S | Save the label under a new name |
| Ctrl+E | Export |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+L | Add a text line |

## Views

| Keys | Action |
|---|---|
| 2 | 2D layout |
| 3 | 3D preview |
| B | Both views |
| F | Fit the label in the view |
| G | Layout guides on or off |
| Drag (3D) | Turn the view |
| Right drag or Shift drag (3D) | Move the view |
| Wheel (3D) | Zoom |

## Sets panel

| Keys | Action |
|---|---|
| / | Search the set list |
| Up, Down | Move through the sets while the search box is selected |
| Enter | Use the highlighted set |

## Everywhere

| Keys | Action |
|---|---|
| Enter | Confirm a dialog; in the Properties panel, apply the field |
| Esc | Close a menu, a dialog or the About screen |
| F1 | Keyboard shortcuts |

Single-key shortcuts do not apply while typing in a field.
