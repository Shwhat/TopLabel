# Getting started

This page covers the first sign-in and making a first label.

## First sign-in

1. Open TopLabel in a browser. A new server shows the sign-in page with Create account selected and the note "This server has no accounts yet."
2. Enter a user name (3 to 32 letters, digits, dots, dashes or underscores, starting with a letter or digit) and a password of at least 8 characters, twice.
3. Select Create account. TopLabel opens.

The first account can always be created. After that, new accounts can only sign up when the server setting `TOPLABEL_SIGNUP` is `true` (see [Technical](/about/technical)).

## The library

On a new server the symbol library downloads by itself when the server starts. The status bar shows "Downloading the library" and the step it is on. When it finishes, the Sets panel fills with sets. If the Sets panel shows "The symbol library is not downloaded yet", select **Refresh library**.

## The first label

1. In the Sets panel, type part of a set name or code in the search box, for example `neo`.
2. Click the set. The label is built in the work area: the symbol in the upper part and the set name and code below it.
3. Adjust the label in the Properties panel, for example the rarity of the symbol or the size.
4. Select **Bambu 3MF** on the Home tab to download the label as a Bambu Studio project, or **STL** for a single mesh.
5. Select **Save** (Ctrl+S) and give the label a name to keep it in the Saved labels panel.

## Where things are

| To | Use |
|---|---|
| Pick a set | Sets panel, Sets view |
| Make a basic land or watermark label | Sets panel, Lands and watermarks view |
| Change size, layout, symbol, text, depth or colors | Properties panel |
| Change the filament colors | Label tab, Filament colors |
| Export | Home tab or the Export menu |
| Open a saved label | Saved labels panel, or File, Open saved label |
| See demo labels | Help, Open demo labels |
